# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately via [GitHub's private vulnerability reporting](https://github.com/FarukA1/TierGate/security/advisories/new) rather than a public issue. You should receive a response within a few days.

## Supported versions

Only the latest published version of `TierGate.Core` and `TierGate.AspNetCore` is supported.
